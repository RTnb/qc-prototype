# 质检数字化管理系统 · 可点击原型

> 测试用原型，页面里的公司、供应商、产品、单据都是演示数据。在线体验（发给同事直接点）：https://rtnb.github.io/qc-prototype/

对应《建设方案》6.1 节第 2 步「原型确认」：电脑和手机都能用的界面原型，给检验员试用评审。

## 怎么打开

- 电脑：双击 `index.html`。依赖库都在 `vendor/` 文件夹里，不用联网。
- 手机：要把整个文件夹放到网上，或者放在同一个局域网里访问（见下文「给别人体验」）。

右上角可以**切换角色**（检验员 / QC 主管 / 质量经理 / 系统管理员 / 只读用户）。**中 / VI** 按钮用来显示或隐藏越南文。
数据只存在这台浏览器里；想恢复初始演示数据，切换到「系统管理员」，进入 系统管理 →「重置演示数据」。

## 公司表单已做成模版

| 表单 | 系统里的样子 |
|---|---|
| **SL/QR-35 来料检验报告（玻璃杯·中越新版，2026-11-25）** | 表头：订单号、货号、尺寸、供应商、来料数量（批量）、到货日期、检验日期、检验员、检验状态（首次 / 复验）、检验结论<br>**按纸质表分三段**：<br>· 第一部分 S-1 特殊检验水平抽检——包装 / 标识 A1–A6、尺寸 / 重量 / 容量 C1–C3（实测，样本数随 S-1 抽样数走；纸质表「公差本格自填」，系统让检验员当场填 ±%，据此算上下限并自动标红超差）<br>· 第二部分 Level I 一般检验水平抽检——外观 B1–B12、后加工外观 P0–P10（P0 后加工类型选「无」时，P1–P10 和附着力 D4–D6 自动判「不适用」）<br>· 第三部分 单项判定——功能 / 测试 D1–D3（含「热冲击补充记录」，每只单独判定，填工艺浇注温度 / 实测温度 / 结果 / 现象）、后加工附着力 D4–D6、资料 E1–E2；任一项不合格整批拒收，「不适用」不计入<br>抽样：按来料数量自动算 S-1 和 Level I 两段各抽几只（字码照 MIL-STD-105E 表 I，Ac / Re 照表 II-A）；AQL 照纸质表 CR 0、MAJ 2.5、MIN 2.5；箭头指的小批量按纸质表说明取值（n=5、Ac 0 / Re 1，字码 D 用 n=8，字码 E 用 n=20、Ac 1 / Re 2）<br>两段各有独立的「缺陷累计」和判定（S-1 判定 / Level I 判定），第三部分单独判定<br>表底：检验员 / 日期、供应商确认 / 日期、不合格（拒收）处理措施（退货 / 全检挑选 / 让步接收 / 供应商来厂处理 / 其他）、负责人 / 日期、审批 / 日期<br>照片：来料产品照片（全貌、细节）＋ 图片（与样品对比、货堆、外包装 / 标识），不良照片自动汇总 |
| **SL/QR-35 进料检验报告（通用）** | 其他物料（蜡、灯芯、彩盒、外箱）用的简化版：尺寸 / 重量 5PCS、外观、包装标识、性能 |
| **SL/QR-36-02 杯蜡在线巡检稽查表** | 表头：产品名称、订单号/货号、订单数量、生产车间、日期、InlineQC、审核、室内温度、室内湿度、页次<br>检验项：B 蘸灯芯 B1–B5、C 压制蜡柱 C1–C8、D 灌装 D1–D16，共 29 项，每项标了 CR/MAJ/MIN<br>填写方式：每 2 小时「新增一轮」，每轮抽 10PCS；判定项打 ✓/✗，温度、长度等读数项填数值；也可以切到「总表」看和纸质表一样的格子<br>汇总：存在的问题、原因分析、处理措施；巡检项次合计、不良项次合计、巡检不良率 |
| **成品检验报告（中越，2026-11-24 新版）** | 表头：订单号、货号、尺寸（按货号自动带出）、订单数量、验货数量、检验日期、验货员、验货结论、验货状态（首次 / 复验）<br>抽样：**MIL-STD-105E Level I**，按验货数量自动算抽样数；CR 接收 0、拒收 1，MAJ / MIN 的 AQL 表上空白，暂按 2.5 / 4.0<br>检验项（共 57 项，每项分「检验项目 / 标准 / 缺陷等级」三列）：A 外箱 A1–A8、B 产品包装 B1–B14（彩盒、标签）、C 安全性 C1–C4、D 材质、E 规格（尺寸、重量、容量实测 5PCS，±5%）、F 功能（燃烧、香味）、G 外观 G1–G25（异物、表面、灯芯、后加工）<br>等级写「MAJ/MIN」的项，判 NG 时由检验员选等级；「其他」行由检验员自填项目和标准，不用可留空<br>表底：缺陷累计、不合格处理、审批人、负责人<br>图片：大货与样品对比、大货货堆、外包装（必拍），缺陷照片自动汇总 |

所有检验项都是**中文 + 越南文**；报告的排版和纸质表格一致（表头、抽样计划、序号/检验项目/检查结果/CR/MAJ/MIN、缺陷累计、表底），另外附上照片和追溯二维码。

**判定规则**：每个 NG 项填「不良数」，计入它所属等级（CR/MAJ/MIN）的「缺陷累计」。任何一个等级的缺陷数达到拒收数，系统就建议判「不合格」；审核人可以改判为合格、不合格或待定。判 NG 的项必须写检查结果并拍照（可以在模版里关掉）。进料新版的第三部分是**单项判定**：任一项判 NG 整批拒收，判「不适用」的不计入。

**拍照规则（报告里每一项都要有照片作证据）**：
- **基础信息照片**：每张单据都必须拍，合格也要拍。
  - 成品：按第三方验货报告的常见分类，共 20 个照片位：货物与抽样（货堆、抽箱）、外箱（正唛、侧唛、尺寸、毛重、开箱、摔箱）、产品包装（彩盒正面/背面、标签与条码、警示标签）、产品（与样品对比、正面、侧面底部、灯芯俯视）、测量与测试（尺寸、称重、燃烧 2 张）。缺陷照片自动汇总。
  - 一张清单照片会**自动引用到它能证明的检验项**，例如拍了「外箱正唛」，A1 印刷内容、A5 条码就自动有照片，不用重复拍。
  - 进料新版：来料产品照片（全貌、细节 / 标识）＋ 图片（与样品对比、货堆、外包装 / 标识），共 5 个照片位。
  - 巡检：生产线现场、当班首件；另外每轮巡检至少拍 1 张现场照片。
- **成品每个检验项都必须拍照**，合格的也要拍；**进料新版按纸质表只要求来料照片 + 不良照片**（想改成每项必拍，在「模版管理」里把拍照要求改成「每项必拍」即可）；判 NA 的项不用拍。
- 一张照片能证明多个项目时（比如一张外箱照片同时证明 A1–A5），可以点「选本单已拍」直接引用，不用重复拍。
- **判不合格的项，必须当场新拍一张不良部位的照片**，照片会标红「不良」；引用的照片不算。这条不能在模版里关闭。
- 以上要求可以在「模版管理」里按模版调整（每项必拍 / 只拍不合格、基础照片拍哪些、拍几张）。
- 成品、巡检的报告里每个检验项旁边直接显示照片缩略图，点开能看大图；不良照片有红框。进料新版的报告按纸质表把照片集中放在「来料产品照片」和「图片」两栏，不良照片单独汇总。

**尺寸、重量、外观三类都有实测数据**：
- 进料新版：C1 尺寸（杯高、口径、壁厚）、C2 重量、C3 容量，样本数跟着 S-1 抽样数走；标准值按物料规格带出，公差按纸质表「本格自填」由检验员当场填 ±%，系统据此算上下限并标红超差。
- 其他物料（蜡、灯芯、彩盒、外箱）用通用进料模版：尺寸和重量各 5PCS，标准值按规格书带出，带不出时检验员当场填写。
- 巡检：D10 最终液面高度、D12 称重按产品规格自动带出标准值和上下限，超出范围的格子标红；新增「D17 产品外观」一项。
- 成品：E1 尺寸（杯高、口径）、E2 重量、E3 容量实测 5PCS，无特殊要求按 ±5%；G17 灯芯长度实测，标准 8–12mm。纸箱、彩盒、标签在 A、B 两组逐项检查并拍照。
- 进料新版不留预置公差（纸质表要求自填）；通用进料和巡检的公差暂按 ±3%，需要确认；成品按新表 ±5%。

**异常：发现即上报、限时处理**（菜单「异常处理」）：
- 检验员在填单过程中，一旦判 NG、实测超差、巡检打 ✗ 或读数超限，系统马上自动保存单据、登记异常，并通知 QC 主管，不用等提交。
- 按等级限时处理：CR 1 小时、MAJ 2 小时、MIN 4 小时（在 系统管理 → 系统参数 里改）。页面显示剩余时间，超时标红并升级给质量经理。
- 主管「接手处理」后选处置方式、写处理措施，然后关闭。巡检的处理结果会自动写进巡检表的「存在的问题 / 处理措施」。
- 工作台最上方和左侧菜单常驻显示待处理、超时的异常数；检验员也能看到自己上报的异常处理到哪一步。异常记录可以导出 Excel。

## 需要你确认的地方（目前是我先填的值）

1. **成品的 MAJ、MIN 的 AQL**：新版成品验货单上是空白，我先按 MAJ 2.5、MIN 4.0 填，可以在模版里改。
2. **热冲击的温度 / 时间**：纸质表写明「按指导书或工艺单填写，不预填限值」，所以系统只记录工艺浇注温度和实测温度，不自动判定超限；只按「每只合格 / 不合格」判 D1。
3. **巡检读数项的单位和上下限**（沾蜡槽温度、灌蜡温度、液面高度、称重等）：现在只记录数值，不会自动判 NG。按工艺卡在模版里填上上下限后，超出范围会自动标红。
4. 供应商、物料规格（杯高、口径、壁厚、重量）、产品和客户都是演示数据，正式使用时用 Excel 导入真实数据。

## 2026-11-25 更新：来料检验报告换成三段式中越新版

- 按新给的《玻璃杯来料检验报告_中越.xlsx》重做了进料模版（SL/QR-35 v2）：分 S-1 抽检、Level I 抽检、单项判定三段，每段独立算样本数、AQL、缺陷累计和判定；表头字段、说明、照片区、表底签字区都按纸质表排。
- 玻璃杯来料自动套这个新模版；其他物料仍用「进料检验报告（通用）」。旧模版的历史单据不受影响（单据会记住当时的模版版本）。
- 浏览器里如果还看到旧的演示数据，到「系统管理 → 重置演示数据」刷一次即可。
